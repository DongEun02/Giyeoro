# 기여로

기여로는 GitHub에 흩어진 오픈소스 Pull Request를 자동으로 모아 프로젝트별로 정리하고, 하나의 포트폴리오 링크로 공유하는 서비스입니다.

GitHub에는 수많은 프로젝트와 이슈가 있지만 처음 기여하는 사람은 어떤 저장소가 계속 관리되고 있는지, 어떤 작업부터 시작해야 하는지 판단하기 어렵습니다. 기여로는 사용자의 경험과 저장소의 최신 상태를 함께 분석해 선택지를 줄이고, 기여 과정을 단계적으로 안내합니다.

## 기여로가 해결하려는 문제

- 여러 저장소에 흩어진 기여 이력을 한눈에 보여주기 어렵습니다.
- 한 프로젝트에 PR이 많으면 개별 PR 목록만으로는 기여의 흐름이 보이지 않습니다.
- 이력서나 프로필에 공유할 수 있는 읽기 쉬운 기여 페이지가 필요합니다.

## 주요 기능

- **GitHub PR 자동 동기화**: 공개된 외부 저장소에 작성한 열린 PR과 병합된 PR을 자동으로 가져옵니다.
- **프로젝트별 자동 정리**: 같은 저장소의 PR을 하나의 프로젝트 카드로 묶고 병합 수와 변경 규모를 요약합니다.
- **간편한 공개 범위 관리**: 개별 PR을 하나씩 정리하지 않고 프로젝트 전체를 숨기거나 다시 표시합니다.
- **기여 포트폴리오 공유**: GitHub에서 병합이 확인된 PR을 읽기 전용 공개 링크로 공유합니다.

## 추천 방식

기여로는 단순한 인기나 프로젝트 규모보다 사용자가 실제로 시작할 수 있는지를 우선합니다. DeepWiki에 등록된 프로젝트를 후보 카탈로그로 사용하되, 대형 프로젝트도 제외하지 않습니다. 대신 개별 이슈의 라벨·본문·논의량을 바탕으로 작업 범위와 난이도를 판단하고, 저장소가 최근에도 관리되는지와 기여 절차가 준비되어 있는지를 함께 확인합니다.

이슈 추천 전에는 지정된 담당자와 연결된 Pull Request뿐 아니라 최근 댓글의 작업 의사 표현도 확인합니다. 댓글 전체를 확인할 수 없거나 이미 다른 기여자가 작업을 맡겠다고 밝힌 이슈는 자동 추천에서 제외합니다.

추천 결과에는 판단 근거를 함께 표시해 사용자가 프로젝트를 직접 비교하고 선택할 수 있도록 합니다.

DeepWiki 후보 목록과 GitHub 메타데이터는 Neon Postgres의 저장소 카탈로그에 동기화합니다. 추천 요청 시 전체 목록을 다시 수집하지 않고 선택 언어의 후보만 조회하며, 실제 이슈 상태는 GitHub에서 최신 정보로 검증합니다.

## 데이터와 권한

맞춤 추천과 PR 동기화는 공개 GitHub 저장소와 공개 활동만 사용합니다. 비공개 저장소 권한은 요청하지 않습니다. 마이페이지는 GitHub의 기본 프로필 정보, 저장한 작업, PR 동기화 결과와 제외 목록을 계정별로 보관하며 같은 계정으로 로그인하면 다른 브라우저나 기기에서도 이어서 관리할 수 있습니다. 공개 포트폴리오는 읽기 전용이며 방문자에게 편집 권한을 제공하지 않습니다.
