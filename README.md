# 기여로

기여로는 여러 GitHub 저장소에 흩어진 공개 Pull Request를 프로젝트별로 모아 보여주고, 병합된 기여를 포트폴리오 링크로 공유하는 서비스입니다.

## 현재 제공하는 기능

- **GitHub 로그인**: `read:user` 권한으로 프로필을 확인합니다. 비공개 저장소 접근 권한은 요청하지 않습니다.
- **PR 동기화**: 로그인한 사용자가 작성한 공개 외부 저장소의 열린 PR과 병합된 PR을 가져옵니다. 저장소는 스타 50개 이상이며 보관 또는 비활성화 상태가 아니어야 합니다. 이미 가져온 PR이 닫히면 동기화 때 상태를 갱신합니다.
- **프로젝트별 대시보드**: PR을 저장소별로 묶고 병합·진행 중인 PR 수, 변경 파일과 코드 증감량을 보여줍니다. 프로젝트 전체를 숨기거나 다시 표시할 수 있습니다.
- **공개 포트폴리오**: `/portfolio/:login`에서 숨기지 않은 병합 PR만 읽기 전용으로 보여줍니다. 이 페이지는 동기화와 공개 설정에 따라 바뀝니다.
- **공유본 링크**: 마이페이지의 **포트폴리오 공유** 버튼은 현재 공개 포트폴리오를 저장하고 `/share/:snapshotId` 링크를 복사합니다. 공유본은 생성 시점의 내용으로 유지되므로 이후 PR을 동기화하거나 프로젝트를 숨겨도 기존 공유본에는 반영되지 않습니다. 변경된 내용을 공유하려면 새 링크를 만드세요.

마이페이지에 들어가면 동기화를 확인하며, 마지막 조회 후 24시간이 지났을 때 GitHub를 다시 조회합니다. **지금 동기화** 버튼으로 즉시 갱신할 수 있습니다. GitHub 검색 결과는 최근 업데이트된 PR 최대 300개까지 확인하므로 기여가 많을 때는 이전 PR이 누락될 수 있습니다.

## 사용 방법

1. 홈에서 **GitHub로 시작하기**를 눌러 로그인합니다.
2. **내 기여**에서 동기화 결과와 프로젝트별 PR을 확인합니다.
3. 공개 목록에서 제외할 프로젝트는 **프로젝트 숨기기**를 누릅니다. **숨긴 프로젝트**에서 다시 표시할 수 있습니다.
4. **공개 페이지 미리보기**로 현재 포트폴리오를 확인한 뒤 **포트폴리오 공유**로 공유본 링크를 만듭니다.

## 로컬 실행

Node.js와 PostgreSQL 데이터베이스가 필요합니다. GitHub OAuth 앱의 callback URL은 `http://127.0.0.1:5173/api/auth/github/callback`로 설정합니다.

```bash
npm install
cp .env.example .env.local
```

`.env.local`에 다음 값을 설정합니다.

| 변수 | 용도 |
| --- | --- |
| `DATABASE_URL` | PostgreSQL 연결 문자열 |
| `DATABASE_URL_UNPOOLED` | 마이그레이션에 사용할 직접 연결 문자열. 없으면 `DATABASE_URL` 사용 |
| `GITHUB_OAUTH_CLIENT_ID` | GitHub OAuth 앱의 Client ID |
| `GITHUB_OAUTH_CLIENT_SECRET` | GitHub OAuth 앱의 Client secret |
| `AUTH_SESSION_SECRET` | 세션 서명용 비밀 값. 32자 이상 |
| `GITHUB_TOKEN` | 서버에서 공개 PR을 조회할 GitHub API 토큰 |
| `APP_URL` | 서비스 주소. 로컬에서는 `http://127.0.0.1:5173` |

```bash
npm run db:migrate
npm run dev
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. `npm run build`로 타입 검사와 프로덕션 빌드를, `npm test`로 테스트를 실행할 수 있습니다.

## 데이터와 공개 범위

GitHub 프로필, 동기화한 공개 PR, 숨긴 프로젝트와 동기화 상태는 계정별로 데이터베이스에 저장됩니다. 로그인 전 브라우저에 저장된 작업 목록이 있으면 로그인 후 계정으로 옮깁니다. 공개 포트폴리오와 공유본은 로그인 없이 볼 수 있으며 방문자에게 편집 권한을 제공하지 않습니다.
